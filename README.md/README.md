# 🎓 Student Management System

A role-based Student Management System developed using PHP, MySQL and PDO.

## 📖 About

This project was developed during my Software Engineering Internship.

The system provides different panels for administrators, academicians and students. Each user has role-based authorization and can only access the features assigned to their role.

---

## 🚀 Features

### Administrator
- Login
- Student Management (CRUD)
- Academician Management (CRUD)
- Faculty Management
- Department Management
- Course Management
- Course Assignment
- Announcement Management
- Role-based Authorization

### Academician
- Login
- View Assigned Courses
- View Students
- Grade Management
- Announcements

### Student
- Login
- View Courses
- View Grades
- View Announcements

## ⚙️ Installation

1. Clone the repository.
2. Move the project into the `xampp/htdocs` directory.
3. Import the SQL file into MySQL.
4. Start Apache and MySQL using XAMPP.
5. Open:

```
http://localhost/student_project
```
